# 🤖 Pose2Skill-Robot
## دليل التشغيل والاستخدام - حقيبة التسليم النهائية

### 📌 نبذة سريعة
مشروع تطبيقي لمقرر **معالجة الصور (عملي) - المستوى الرابع** بكلية الحاسبات والعلوم التطبيقية — جامعة إب.
يقوم النظام بالتقاط حركة الجسم البشري عبر كاميرا الويب العادية (RGB)، واستخراج 33 نقطة مفصلية ثلاثية الأبعاد عبر `MediaPipe Pose`، وحساب زوايا مفاصل الأطراف العلوية والسفلية كينماتيكياً مع تصفيتها بمرشح التنعيم الأسي ($EMA$)، ونقلها لحظياً لتوجيه روبوت بشري محاكى (**SoftBank NAO**) داخل بيئة **Webots**، مع ميزة حفظ وتشغيل المهارات الحركية المستقلة بصيغة JSON.

---

### ⚙️ متطلبات التشغيل (Prerequisites)
1. نظام تشغيل **Windows 10 / 11**.
2. **Python 3.10+**.
3. بيئة محاكاة **Cyberbotics Webots** (الإصدار R2023b أو R2025a).
4. تثبيت المكتبات عبر الأمر:
```bash
pip install -r 02_الكود_المصدري_الأساسي/requirements.txt
```

---

### 🚀 خطوات التشغيل بنقرة واحدة (1-Click Launch)
توجه إلى مجلد `05_أدوات_التشغيل_السريع/`:
* اضغط نقراً مزدوجاً على **`تشغيل_النظام_بالكامل.bat`**.
* سيقوم السكريبت بفتح محاكاة Webots تلقائياً وتحميل عالم الروبوت NAO، ثم فتح نافذة الكاميرا والتوجيه اللحظي.

---

### 🎮 أزرار التحكم والاختصارات
يمكن التحكم إما بالماوس عبر الأزرار المدمجة في نافذة الكاميرا، أو عبر لوحة المفاتيح:
| الزر | الوظيفة |
| :---: | :--- |
| **`T`** أو **`المسافة`** | بدء / إيقاف تسجيل مهارة جديدة (حفظ في JSON) |
| **`P`** | إعادة تشغيل آخر مهارة تم تسجيلها على الروبوت |
| **`1`** | تشغيل مهارة ركلة الفنون القتالية (Martial Arts Kick) |
| **`2`** | تشغيل مهارة القرفصاء الرياضي (Athletic Squat) |
| **`3`** | تشغيل مهارة تحية النصر المزدوجة (Double Arm Salute) |
| **`4`** | تشغيل مهارة التلويح والترحيب (Wave Greeting) |
| **`Q`** | خروج نظيف وإغلاق الاتصال |
