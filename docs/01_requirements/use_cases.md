## UC-01: تسجيل عرض بشري جديد (Record Human Demonstration)

| الحقل | التفاصيل |
|-------|----------|
| **المعرّف** | UC-01 |
| **الاسم** | Record Human Demonstration |
| **الفاعل الرئيسي** | Researcher |
| **الأولوية** | Must Have |
| **الشرط المسبق** | الكاميرا متصلة وتعمل، النظام شغّال |
| **شرط النجاح** | مقطع فيديو محفوظ + تأكيد بدء المعالجة |

### السيناريو الأساسي (Main Flow)
1. يفتح الباحث واجهة المستخدم أو يشغل الأمر `ros2 service call /pose2skill/start_recording`
2. يقف الإنسان أمام الكاميرا في مسافة 1–3 متر
3. ينفّذ الإنسان المهمة (مثال: يلتقط كأساً ويضعه في صينية)
4. يوقف الباحث التسجيل عبر `stop_recording`
5. يحفظ النظام الفيديو في `data/demonstrations/<task_name>/demo_<id>.mp4`
6. يبدأ النظام تلقائياً في معالجة الفيديو (طبقة الإدراك)

### السيناريوهات البديلة
- **A1**: الكاميرا تنقطع → يظهر تحذير، يوقف التسجيل ويطلب الإعادة
- **A2**: إضاءة ضعيفة → يحذر النظام من جودة الإدراك المنخفضة
- **A3**: تغذية فيديو محفوظ مسبقاً → يقبل النظام ملفات MP4/AVI

## UC-02: استخلاص Skill Graph تلقائياً

| الحقل | التفاصيل |
|-------|----------|
| **المعرّف** | UC-02 |
| **الاسم** | Automatic Skill Graph Extraction |
| **الفاعل الرئيسي** | System (مُشغَّل تلقائياً بعد UC-01) |
| **الأولوية** | Must Have |
| **الشرط المسبق** | فيديو واحد على الأقل محفوظ في `data/demonstrations/` |
| **شرط النجاح** | Skill Graph محفوظ بصيغة YAML في `data/skill_graphs/` |

### السيناريو الأساسي
1. يقرأ النظام مقطع الفيديو إطاراً بإطار
2. **طبقة الإدراك**: يستخرج إحداثيات الجسم، اليد، والأجسام
3. **طبقة التجزئة**: يصنّف كل إطار إلى أحد الأفعال السبعة
4. **كشف الاتصال**: يحدد لحظات الإمساك والإفلات الدقيقة
5. **بناء Graph**: يبني عقد الأفعال مع شروط الانتقال وقيود الإتاحة
6. يحفظ الـ Skill Graph ويرسله على `/pose2skill/skill_graph`

### السيناريوهات البديلة
- **A1**: K عروض متعددة → يجمّع الـ Graph من جميع العروض
- **A2**: ثقة تصنيف منخفضة → يطلب عرضاً إضافياً

## UC-03: تنفيذ مهمة على Franka Panda

| الحقل | التفاصيل |
|-------|----------|
| **المعرّف** | UC-03 |
| **الاسم** | Execute Task on Franka Panda |
| **الفاعل الرئيسي** | Robot Engineer |
| **الأولوية** | Must Have |
| **الشرط المسبق** | Skill Graph متاح + Gazebo شغّال + Franka spawned |
| **شرط النجاح** | الروبوت ينجح في المهمة داخل المحاكاة |

### السيناريو الأساسي
1. يختار المهندس المهمة والـ Skill Graph عبر Dashboard
2. يستدعي `execute_task` service
3. **الطبقة 5**: يحوّل Skill Graph إلى أهداف EE لـ Franka
4. **MoveIt 2**: يحل IK ويخطط مسار خالٍ من التصادم
5. **Gazebo**: ينفذ المسار ويتحقق من نجاح المهمة
6. يسجل النتائج: SR, TCT, Jerk في ملف CSV
7. يعرض النتائج على Dashboard

### السيناريوهات البديلة
- **A1**: IK Singularity → يجرب وضعيات بديلة (Redundancy Resolution)
- **A2**: تصادم محتمل → يُعيد التخطيط تلقائياً
- **A3**: هدف خارج مساحة العمل → يُرسل تحذيراً ويتوقف

## UC-04: نقل المهارة إلى UR5e

| الحقل | التفاصيل |
|-------|----------|
| **المعرّف** | UC-04 |
| **الاسم** | Cross-Embodiment Skill Transfer to UR5e |
| **الفاعل الرئيسي** | Robot Engineer |
| **الأولوية** | Must Have |
| **الشرط المسبق** | UC-03 نجح + UR5e spawned في Gazebo |
| **شرط النجاح** | CETI ≥ 85% |

### السيناريو الأساسي
1. يختار المهندس "Transfer to UR5e" في Dashboard
2. **الطبقة 5 (للـ UR5e)**: يُعيد تعيين نفس Skill Graph لـ UR5e (DoF=6)
3. **MoveIt 2 (UR5e)**: يخطط مساراً متوافقاً مع قيود UR5e المختلفة
4. ينفذ وتُسجّل النتائج
5. يحسب النظام تلقائياً CETI = SR_UR5e / SR_Franka × 100%

## UC-05: تشغيل بروتوكول المقارنة الكاملة

| الحقل | التفاصيل |
|-------|----------|
| **المعرّف** | UC-05 |
| **الاسم** | Run Full Benchmark Protocol |
| **الفاعل الرئيسي** | Researcher |
| **الأولوية** | Must Have |
| **المدة المتوقعة** | 4–8 ساعات (20 تكراراً × 4 مهام × 2 روبوت × 3 طرق) |
| **شرط النجاح** | ملف CSV كامل + جدول ملخص |

### السيناريو الأساسي
```bash
python scripts/run_benchmark.py \
  --tasks all \
  --robots franka_panda ur5e \
  --methods direct_joint cartesian_clone pose2skill \
  --trials 20 \
  --output experiments/logs/
```
1. يشغل البروتوكول تلقائياً جميع التجارب بالتسلسل
2. يعيد تهيئة Gazebo قبل كل تجربة
3. يسجل 7 مقاييس لكل تجربة
4. يولد جدولاً إحصائياً شاملاً

## UC-07: حفظ وتحميل Skill Graph

### السيناريو
```bash
# حفظ Skill Graph
ros2 service call /pose2skill/save_skill_graph \
  pose2skill_msgs/srv/SaveSkillGraph \
  '{filename: "pick_cup_v1.yaml", task_name: "pick_cup"}'

# تحميل Skill Graph
ros2 service call /pose2skill/load_skill_graph \
  pose2skill_msgs/srv/LoadSkillGraph \
  '{filename: "pick_cup_v1.yaml"}'
```
